1a Interactive — tap through it. Sun mode is on by default.
01 · WHAT I ASSUMED
One job per day, many clock-in codes against it. The code — not the job — is the thing a crew member switches all day, so the code is the loudest control on the home screen.
Codes mirror JobTread cost codes and sync on clock-out. Nothing is entered twice.
Photos are one tap plus one tag: Before / During / After. Everything else (area, code, time, who) is inferred.
The app asks for photos at the moments they're actually owed, and only blocks when the answer is unambiguous: you said the code was finished, or you're ending the day. Everything else is a nudge, not a wall.
Foreman is the same app with a crew block added — no separate build.
02 · WHY IT LOOKS LIKE THIS
Sun mode is the default, not the exception. Near-black ground with white type is the highest-contrast, lowest-glare combination on a phone at noon on a roof — and it's already the system's --surface-band language. The toggle is top-right, one tap, no menu.
Every primary control is 76 px tall minimum, full-bleed to the screen edges, with 14 px of dead space between it and the next target. Nothing important is smaller than a gloved thumb.
Green means go, white means stop. Green is never decoration here — it's the clock-in action, the live dot, and the AFTER tag. Navy carries chrome only.
Three tabs. No hamburger, no settings, no search.

THE FLOW END TO END
01Arrive. One green button. Tap it and the code list opens — you can't clock in without saying what you're doing.
02Timer runs on the near-black band. Readable from arm's length in direct sun.
03Move to a new task → SWITCH CODE asks one question: is this code finished? NO switches straight through. YES requires the after photo before the next code can start.
04Photos are prompted, not remembered: a BEFORE sheet the moment a code starts (skippable, one photo clears it), an amber strip until it's satisfied, and a push notification at 5 minutes that reopens the photo screen and copies the office.
05DAY LOG holds photos, material counts and notes. One send at the end.
06CLOCK OUT shows the day's totals and will not commit without an after photo of the code you're on.
